# Uninstall on Windows, Steam version

Run the program again (`tzar-widescreen-windows.exe`) and choose to remove the mod. It puts the game's original files
back and removes everything it added. If you deleted it, [download it again][download].

## Without the program

Steam can put the game's files back: in your Library, right-click Tzar, then **Properties**, **Installed Files**,
[**Verify integrity of game files**][verify]. It also resets the game's settings.

Then delete what the mod added to the game folder (right-click Tzar, **Manage**, **Browse local files**): `ddraw.dll`,
`ddraw.ini`, `Shaders` and `tzar-widescreen-backup`.

[download]: https://github.com/bruno-gelb/ttbotc_resolution_mod/releases/latest/download/tzar-widescreen-windows.exe
