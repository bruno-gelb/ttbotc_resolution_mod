# Uninstall on Windows, GOG version

Run the program again (`tzar-widescreen-windows.exe`) and choose to remove the mod. It puts the game's original files
back and removes everything it added. If you deleted it, [download it again][download].

## Without the program

GOG's tools can put the game's files back:

- **GOG Galaxy:** on the game's page, the settings button next to **Play**, then **Manage installation**,
  **Verify / Repair**.
- **Heroic:** the game's **Verify and Repair**.
- **GOG's offline installer:** run it again, into the same folder.

Then delete what the mod added to the game folder, the one with `Tzar.exe` in it: `ddraw.dll`, `ddraw.ini`, `Shaders`
and `tzar-widescreen-backup`.

[download]: https://github.com/bruno-gelb/ttbotc_resolution_mod/releases/latest/download/tzar-widescreen-windows.exe
